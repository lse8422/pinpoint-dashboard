# 핀포인트(Pinpoint) — 화성시 언론보도 대시보드

화성시 홍보 담당 부서가 **매일 아침 5분 안에 오늘 확인할 보도를 파악하도록** 만든 정책 모니터링 대시보드입니다.
2026 화성시 AI·DATA 공모전 지정과제 16번(정책 모니터링형) 수행 결과물입니다.

- **바로 보기** — <https://pinpoint-dashboard-20z.pages.dev/>
- **간편 화면(모바일)** — <https://pinpoint-dashboard-20z.pages.dev/m.html>

## 30초 체험 순서

1. 맨 위 **오늘 확인할 것** 3건을 봅니다. 부정 보도를 사건 단위로 묶어 우선순위를 매긴 결과입니다.
2. 분야별 비중 그래프 아래에서 **안전**을 누릅니다. 그 분야의 긍정·중립·부정 비율과 날짜별 추이가 열립니다.
3. **관심 부서·기관·사업**에 `환경재단`을 입력해 등록합니다. 그 이름이 들어간 보도만 모입니다.
4. 오른쪽 위 **간편 보기**를 누르면 출근길용 화면으로 넘어갑니다.

## 데이터

두 종류를 **섞지 않고 구분해서** 보여줍니다. 수집 범위가 다르기 때문에 섞으면 비교가 왜곡됩니다.

| 구분 | 출처 | 기간 | 건수 |
|---|---|---|---|
| 검증본 | 빅카인즈(BIG KINDS) | 2026-06-06 ~ 2026-08-06 | **1,026건** (화성시 무관 754건 제거 후) |
| 자동수집분 | 구글 뉴스 RSS | 2026-08-02 ~ 매일 갱신 | **570건** (2026-08-21 기준) |

화면 상단에 두 출처와 마지막 갱신 시각을 항상 표시하고, 추이 그래프에서도 실선(검증본)과 점선(자동수집)으로 나눕니다.

데이터 형식 — `news_data.json`(검증본), `news_live.json`(자동수집분)

```json
{
  "date": "2026-08-20",
  "cat": "행정",
  "senti": "부정",
  "title": "기사 제목",
  "summary": "AI가 제목을 읽고 쓴 한 줄 정리",
  "kw": ["키워드1", "키워드2", "키워드3"]
}
```

`cat`은 교통·환경·행정·문화관광·산업경제·안전·복지 7종, `senti`는 긍정·중립·부정 3종입니다.

## 매일 아침 6시에 벌어지는 일

서버가 없는데도 매일 갱신됩니다. GitHub Actions가 대신 돌기 때문입니다.

```
06:00  GitHub Actions 기동 (cron: "0 21 * * *" UTC)
  ↓    collect.py 실행
  ①    구글 뉴스 RSS에서 화성시 관련 기사 수집
  ②    중복·무관 기사 제거 (제목 단서 없음 / 동음이의어)
  ③    AI가 15건씩 묶어 분야·긍부정·한 줄 정리·키워드 판정
  ④    부정 보도를 제목 유사도로 묶어 사건 단위 이슈 구성
  ⑤    이슈 점수 계산 · 분야별 급증 탐지
  ⑥    AI가 집계 결과를 읽고 브리핑 문장 작성
  ⑦    news_live.json 커밋 → Cloudflare Pages 자동 배포
```

**2026-08-14부터 7일 연속, 정기 실행 7회, 실패 0회.** 이 값은 GitHub API에서 실제로 읽어 화면에 표시합니다.

AI는 **claude-haiku-4-5-20251001**을 씁니다. 제목만 처리하므로 하루 3~5센트, 월 1달러 수준입니다.

## 기능

**오늘 확인할 것** — 부정 보도를 제목 유사도(자카드 0.35, Union-Find)로 묶고, 최신성·확산 매체 수·기사 수·지속성으로 점수를 매겨 상위 3건을 맨 위에 둡니다. 점수가 같으면 같은 번호로 표시하고 "순서는 우열이 아니다"라고 화면에 밝힙니다.

**분야별 급증** — 최근 3일과 그 이전 12일의 하루 평균을 비교해 2배 이상이면 알립니다. 배수만 말하지 않고 **비교한 원래 건수를 함께** 표시합니다(예: 최근 3일 8건 / 이전 12일 2건).

**분야별 상세** — 분야를 누르면 그 안의 긍정·중립·부정 비율과 월별 추이가 열리고, 같은 기간 전체 평균과 비교합니다. 고르는 자리는 그래프 아래·도넛·검색줄 세 곳이며 모두 같은 함수를 부릅니다.

**관심 부서·기관·사업** — 담당자가 이름을 등록하면 그 이름이 제목·키워드에 들어간 보도만 모아 건수·긍부정 비율·기간별 추이를 보여줍니다. **자동 소관부서 분류는 하지 않습니다** — 제목에 부서·기관 이름이 적힌 기사가 1,596건 중 3.8%뿐이라 추측하면 틀리기 때문입니다. 등록 목록은 `localStorage`에 저장되어 그 브라우저에만 남습니다.

**AI 브리핑** — 집계 결과를 AI가 읽고 문장을 씁니다. **숫자는 코드가 계산하고 AI는 문장만 씁니다.** 브리핑 작성 시각과 데이터 갱신 시각을 따로 표시합니다.

**그 밖에** — 키워드 TOP 8, 기간 선택(전체·최근 7일·최근 30일·직접 지정), 분야 필터, 제목·키워드 검색, 페이지네이션, 다크 모드.

**간편 화면(`m.html`)** — 출근길용. 급증 경고, 오늘 확인할 3건, 최근 2주 추이, 분야별 부정 비율만 남겼습니다. 차트 라이브러리 없이 HTML·CSS로만 그려 373KB입니다.

## 알려진 한계

정직하게 적습니다. 발표에서도 같은 내용을 말합니다.

- **본문을 읽지 않습니다.** AI는 기사 제목만 처리합니다. 그래서 "AI 요약"이 아니라 "AI 한 줄 정리"라고 부릅니다.
- **실시간이 아닙니다.** 하루 한 번, 아침 6시에 갱신됩니다.
- **소관부서를 자동 판정하지 않습니다.** 위에 적은 이유 때문입니다.
- **이슈 묶기는 "동일 사건 확정"이 아니라 "유사 제목 묶음"입니다.** 제목이 비슷하면 다른 사건이 함께 묶일 수 있습니다.
- **분류 정확도는 표본 재판정 결과만 있습니다.** `검수_100건.html`로 사람이 직접 채점할 수 있게 해 두었고, 확정된 사람 검수 수치가 나오기 전에는 화면에 정확도를 표시하지 않습니다.

## 실행 방법

브라우저로 파일을 직접 열면(file://) 보안 정책 때문에 데이터 로드가 막힐 수 있습니다. 로컬 서버로 실행해 주세요.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 으로 접속합니다.

## 기술 구성

순수 HTML + CSS + JavaScript입니다. 프레임워크·백엔드·데이터베이스·빌드도구가 없습니다.

- Chart.js — 차트
- flatpickr — 날짜 범위 선택
- Pretendard — 본문 서체

**모든 라이브러리를 저장소에 포함해 외부 네트워크 요청이 0건입니다.** 심사 당일 네트워크가 불안정해도 화면이 뜨는 것을 최우선으로 삼았습니다.
