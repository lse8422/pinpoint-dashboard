# 핀포인트(Pinpoint) — 화성시 언론보도 대시보드

화성시 관련 언론보도를 수집·분류·분석하여 주요 이슈와 부정 보도 흐름을 한눈에 파악하는 정책 모니터링 대시보드입니다.
2026 화성시 AI·DATA 공모전 지정과제 16번(정책 모니터링형) 수행 결과물입니다.

## 주요 기능

1. **분야 자동 분류** — 기사를 교통·환경·행정·문화관광·산업경제·안전·복지 7개 분야로 AI 분류
2. **키워드 분석** — 기간별 핵심 키워드 TOP 8 추출, 키워드 클릭 시 관련 기사 즉시 검색
3. **기사량 추이 차트** — 전체 기사와 부정 기사를 함께 표시해 여론 급변 시점을 포착
4. **AI 요약 카드** — 기사별 한 문장 요약으로 담당자의 확인 시간 단축
5. **부정 이슈 표시** — 부정 보도를 별도 강조하고 "부정 이슈만" 필터로 모아보기

부가 기능 — 기간 선택(전체·최근 7일·최근 30일·직접 날짜 지정), 분야 필터, 제목·키워드 검색, 다크모드.

## 데이터

- 출처: 빅카인즈(BIG KINDS) 수집 기사
- 기간: 2026-06-06 ~ 2026-08-06
- 건수: **1,026건** (화성시 무관 기사 754건 제거 후 검증본)
- 처리: 수집 → AI 분야 분류·긍부정 판별·한 문장 요약·키워드 추출 → JSON 변환

데이터 형식 (`news_data.json`)

```json
{
  "date": "2026-08-06",
  "cat": "행정",
  "senti": "긍정",
  "title": "기사 제목",
  "summary": "AI가 생성한 한 문장 요약",
  "kw": ["키워드1", "키워드2", "키워드3"]
}
```

## 실행 방법

파일을 브라우저로 직접 열면(file://) 보안 정책 때문에 데이터 로드가 막힙니다. 간단한 로컬 서버로 실행해 주세요.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 으로 접속합니다.

## 기술 구성

- 순수 HTML + CSS + JavaScript (프레임워크 없음)
- Chart.js — 차트 렌더링
- flatpickr — 날짜 범위 선택
- Pretendard — 본문 서체

**모든 라이브러리를 프로젝트 폴더에 포함해 외부 네트워크 요청이 0건입니다.** 서버·데이터베이스 없이 정적 파일만으로 동작하므로 배포 환경이나 네트워크 상태와 무관하게 안정적으로 열립니다.
